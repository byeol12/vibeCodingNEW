# 도메인 규칙 기준

이 문서는 v0 `script.js`의 현재 동작을 v1의 단일 기준으로 고정한다. TypeScript와 SQL 구현은 아래 테스트 벡터를 함께 통과해야 한다.

## 일일 평가와 포인트

- 수업 태도, 참여도, 숙제는 각각 1P다.
- 세 항목이 모두 참이면 도장 보너스 2P다.
- 칭찬 태그가 하나 이상이면 하루 한 번 2P다.
- 세 항목이 모두 참이고 럭키이면 5P다.
- 전월 대비 성장 보너스는 20P, 3일 회복 보너스는 10P다.
- 승인 완료 구매만 지출로 계산한다. 승인 대기는 사용 가능 잔액에서만 예약 차감한다.

| 평가 수 | 칭찬 | 럭키 | 일일 기본 포인트 |
| ---: | :---: | :---: | ---: |
| 0 | 없음 | 아니오 | 0 |
| 1 | 없음 | 아니오 | 1 |
| 2 | 있음 | 아니오 | 4 |
| 3 | 없음 | 아니오 | 5 |
| 3 | 있음 | 아니오 | 7 |
| 3 | 있음 | 예 | 12 |

## 카드 등급

- 조커 사용일은 다른 조건보다 우선하여 J다.
- 평가 1개는 C, 2개는 U다.
- 평가 3개는 스트릭에 포함된다.
- 평가 3개이면서 럭키 또는 해당 날짜 스트릭 10 이상이면 L이다.
- 그 외 평가 3개이면서 해당 날짜 스트릭 5 이상이면 E다.
- 나머지 평가 3개는 R이다.
- 미래 수업일은 미완료로 계산하지 않는다.

## 스트릭과 회복

- 세 평가를 모두 달성하거나 조커를 사용하면 스트릭이 이어진다.
- 부분 달성은 카드는 만들지만 스트릭을 끊는다.
- 최고 스트릭은 현재 스트릭이 끊겨도 유지한다.
- 스트릭 붕괴 이후 도장 3회를 다시 달성하면 붕괴 1건당 회복 보너스를 한 번 지급한다.

## 자기관찰

- 칭찬 태그는 일일 최대 3개다.
- 어려움 태그는 감점하지 않는다.
- 학생만 자기관찰을 작성·수정하며 교사는 읽기만 한다.
- 교사 평가가 하나 이상 입력된 수업일에서만 자기관찰 UI를 노출한다.

## 럭키와 조커

- 세 평가를 처음 완성하는 순간에만 럭키를 한 번 추첨한다.
- 럭키 확률은 10%이며 재체크로 다시 추첨하지 않는다.
- 조커 획득·사용·환불은 후속 `joker_events` 원장에서 추적한다.
- 무작위 결과는 클라이언트가 아니라 신뢰 가능한 서버 작업에서 확정한다.
